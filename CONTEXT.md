# Payment Processing

Асинхронный сервис процессинга платежей: приём платежей по API, обработка через платёжный шлюз в consumer, webhook-уведомления, outbox и DLQ

## Language

Термины предметной области и их смысл здесь. Код, тесты, поля API и доки используют эти слова;
строка _Avoid_ перечисляет синонимы, которым нельзя просочиться обратно. Термин добавляется,
когда получает точный смысл в решении, а не заранее.

**Платёж (Payment)**:
Запрос клиента списать сумму в валюте. Создаётся в статусе `pending`, один раз переходит в
`succeeded` или `failed` и больше не меняется. Сущность внутри сервиса, не транзакция в банке.
_Avoid_: транзакция, заказ, операция

**Ключ идемпотентности (Idempotency key)**:
Строка из заголовка `Idempotency-Key`, которую клиент присылает при создании платежа. Один ключ —
один платёж: повтор запроса с тем же ключом возвращает тот же платёж и не создаёт нового.
_Avoid_: request id, dedup key

**Шлюз (Gateway)**:
Внешняя платёжная система, которой сервис поручает списание. В репозитории — эмуляция с задержкой
и долей отказов; интерфейс тот же, что был бы у реального.
_Avoid_: провайдер, эквайринг, банк

**Outbox**:
Таблица, в которую событие о платеже пишется той же транзакцией, что и сам платёж. Отдельный
relay читает её и публикует в RabbitMQ. Гарантирует, что событие не потеряется, если брокер лежал.
_Avoid_: event log, журнал

**Relay**:
Фоновый цикл, который переносит записи outbox в брокер и помечает их отправленными. Единственный
публикатор событий; API в брокер не пишет.
_Avoid_: publisher, dispatcher

**Consumer**:
Процесс, читающий очередь `payments.new`: обращается к шлюзу, фиксирует статус платежа и
отправляет webhook. Один обработчик на одно сообщение.
_Avoid_: worker, handler (handler — функция внутри consumer)

**Webhook**:
HTTP POST на `webhook_url` платежа с итоговым статусом. Отправляется после фиксации статуса,
повторяется при ошибке доставки.
_Avoid_: callback, notification

**DLQ (Dead Letter Queue)**:
Очередь, в которую RabbitMQ перекладывает сообщение после исчерпания попыток обработки. Сообщения
из неё автоматически не обрабатываются; это место для ручного разбора.
_Avoid_: error queue, карантин
